## Overview

Satellite anomalies are difficult to predict because their timing can depend on historical events, orbital characteristics, seasonality, and space-weather conditions. This project predicts **Time-to-Event (TTE)**: the number of days between one recorded satellite anomaly and the next recorded anomaly for the same satellite.

The project compares three approaches for continuous TTE prediction:

- **Linear Regression** — baseline regression model.
- **Support Vector Regression (SVR)** — nonlinear regression using an RBF kernel.
- **Modified Naive Bayes Survival Model** — a custom survival-oriented approach that estimates probabilities across TTE thresholds and integrates an estimated survival curve to produce a continuous prediction.

## Project results

The final modelling table contains **2,437 TTE observations from 37 satellites**, using **13 active features**. The models were evaluated using shuffled 10-fold cross-validation with `random_state = 42`.

| Model | RAE (%) | MAE (days) | RMSE (days) |
|---|---:|---:|---:|
| Linear Regression | 475.759 | 21.890 | 39.932 |
| SVR | **170.86** | **17.58** | 41.66 |
| Modified Naive Bayes Survival Model | 3,015.14 | 91.73 | 107.40 |

SVR achieved the lowest RAE and MAE, while Linear Regression achieved the lowest RMSE. The modified Naive Bayes survival model had the largest errors on this dataset.

## Data preparation and feature engineering

Three datasets are combined:

- `anom5j.xls`: satellite identifiers, anomaly dates, orbit labels, and altitude.
- `satcat.csv`: satellite catalogue and orbital information.
- `sunspot.csv`: daily sunspot activity aligned to anomaly dates.

The preprocessing workflow:

1. Normalizes satellite names and orbit labels, parses dates, removes invalid dates, and deduplicates same-satellite anomalies recorded on the same day.
2. Builds satellite-level attributes and one-hot encodes orbit categories.
3. Matches satellite catalogue records using normalized names and keeps unambiguous matches.
4. Computes 27-day and 81-day rolling sunspot averages and their difference as a trend feature.
5. Sorts anomaly dates per satellite and calculates TTE as the day difference between consecutive anomalies.
6. Excludes the final anomaly for each satellite because the following event is unknown, removes non-positive gaps and gaps of 365 days or more, and excludes satellites with 20 or fewer valid TTE observations.

The **13 active features** are:

- **Seasonal (2):** `month_sin`, `month_cos`
- **Sunspot (3):** `sun_27`, `sun_81`, `sun_trend`
- **Orbit (6):** `orbit_G`, `orbit_I`, `orbit_C`, `orbit_E`, `orbit_P`, `orbit_V`
- **Anomaly history (2):** `prev_log_gap`, `log_n_prev`

The target column is `tte`, measured in days. Missing feature values are handled within the model pipeline using median imputation; scaling is applied where configured.

## Model details

### Linear Regression

Baseline continuous regression model. Its pipeline uses median imputation, standardization, and Linear Regression.

### Support Vector Regression (SVR)

Uses an RBF kernel with `C = 10.0` and `epsilon = 0.1`. The notebook uses median imputation and standardization before fitting the regressor.

### Modified Naive Bayes Survival Model

This is a custom survival-oriented adaptation, not a standard direct Naive Bayes regression estimator. Gaussian Naive Bayes classifiers estimate the probability that TTE exceeds selected thresholds. Those probabilities form an estimated survival curve, which is integrated to produce a continuous expected-TTE prediction.

## Evaluation

All three models use the same prepared TTE observations, the same 13 active features, and shuffled 10-fold cross-validation with `random_state = 42`.

- **RAE:** Relative Absolute Error, reported as a percentage.
- **MAE:** Mean Absolute Error, in days.
- **RMSE:** Root Mean Squared Error, in days.

The folds are shuffled at the observation level rather than grouped by satellite. Therefore, observations from the same satellite can occur in both training and test folds; the evaluation should not be interpreted as a test of generalization to entirely unseen satellites.
